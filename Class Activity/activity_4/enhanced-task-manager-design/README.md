
# Enhanced Task Manager Design (Week 11)

A Python command-line task manager scaffold demonstrating project
planning, modular design, and separation of concerns.

## Features

- Add normal tasks, due-date tasks, and priority tasks.
- Add multiple tags to tasks.
- List, complete, and delete tasks.
- Save and load tasks from `data/tasks.json`.
- Search, filter, and sort are placeholders for future implementation.

## Requirements

- Python 3.10 or newer
- No third-party packages required.

## Run

Open a terminal in the project root and run:

```powershell
python main.py
```
