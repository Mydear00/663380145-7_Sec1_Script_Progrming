
# ระบบจัดการรายการงานด้วย OOP

## My OOP Task Manager CLI

## 1. รายละเอียดโครงงาน

My OOP Task Manager CLI เป็นโปรแกรมจัดการรายการงานผ่าน Command-Line Interface (CLI) พัฒนาด้วยภาษา Python โดยใช้แนวคิดการเขียนโปรแกรมเชิงวัตถุ (Object-Oriented Programming: OOP)

โปรแกรมแบ่งการทำงานออกเป็นคลาส Task สำหรับแทนรายการงานแต่ละรายการ และคลาส TaskManager สำหรับจัดการรายการงาน รวมถึงการอ่านและบันทึกข้อมูลในไฟล์ JSON

## 2. วัตถุประสงค์

- เรียนรู้การสร้างคลาสและวัตถุใน Python
- เข้าใจการทำงานของ Constructor และ `self`
- ฝึกใช้ Attributes และ Instance Methods
- ฝึกใช้ `__str__()` และ `__repr__()`
- ปรับปรุงโปรแกรมจาก Procedural Programming เป็น OOP
- เรียนรู้การบันทึกและโหลดข้อมูล JSON
- ฝึกแบ่งโค้ดให้เป็นระบบและดูแลรักษาได้ง่าย

## 3. ความสามารถของระบบ

1. เพิ่มรายการงาน
2. แสดงรายการงานทั้งหมด
3. ทำเครื่องหมายว่างานเสร็จแล้ว
4. ลบรายการงาน
5. บันทึกข้อมูลและออกจากโปรแกรม
6. บันทึกข้อมูลลงไฟล์ JSON โดยอัตโนมัติเมื่อมีการเปลี่ยนแปลง

แต่ละงานมีรหัส รายละเอียด สถานะ และระดับความสำคัญ ได้แก่ Low, Medium และ High

## 4. แนวคิด OOP ที่นำมาใช้

### คลาส Task

ใช้แทนรายการงานหนึ่งรายการ โดยมี Attributes ได้แก่ `id`, `description`, `completed` และ `priority`

เมธอดสำคัญ:

- `__init__()` กำหนดค่าเริ่มต้น
- `mark_complete()` เปลี่ยนสถานะงาน
- `to_dict()` แปลงวัตถุเป็น Dictionary
- `__str__()` แสดงข้อมูลงาน
- `__repr__()` แสดงข้อมูลสำหรับตรวจสอบและ Debug

### คลาส TaskManager

ใช้จัดการรายการ Task objects และการจัดเก็บข้อมูล

เมธอดสำคัญ:

- `add_task()` เพิ่มงาน
- `list_tasks()` แสดงรายการงาน
- `complete_task()` ทำเครื่องหมายว่างานเสร็จ
- `delete_task()` ลบงาน
- `_load_tasks()` โหลดข้อมูลจาก JSON
- `_save_tasks()` บันทึกข้อมูลลง JSON
