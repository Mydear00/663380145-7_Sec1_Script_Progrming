# ระบบจัดการรายการงาน (My Task Manager CLI)

## 1. รายละเอียดโครงงาน

ระบบจัดการรายการงาน (Task Manager CLI) เป็นโปรแกรมจัดการงานผ่าน Command-Line Interface (CLI) พัฒนาด้วยภาษา Python เพื่อช่วยให้ผู้ใช้สามารถจัดการรายการงานในชีวิตประจำวันได้อย่างสะดวก โดยสามารถเพิ่ม แสดง ค้นหา กรองสถานะ ทำเครื่องหมายว่างานเสร็จแล้ว และลบรายการงานได้

โปรแกรมจัดเก็บข้อมูลในรูปแบบ JSON ทำให้รายการงานยังคงอยู่หลังจากปิดโปรแกรม และสามารถโหลดข้อมูลกลับมาใช้ได้เมื่อเปิดโปรแกรมครั้งถัดไป

โครงงานนี้จัดทำขึ้นเพื่อฝึกทักษะการเขียนโปรแกรมภาษา Python การแบ่งโค้ดเป็นโมดูล การจัดการข้อผิดพลาด การอ่านและเขียนไฟล์ ตลอดจนการใช้ Git และ GitHub สำหรับควบคุมเวอร์ชันของซอร์สโค้ด

## 2. วัตถุประสงค์

- เพื่อฝึกออกแบบและพัฒนาโปรแกรม CLI ที่สามารถใช้งานได้จริง
- เพื่อเรียนรู้การแบ่งโครงสร้างโปรแกรมออกเป็นโมดูลอย่างเป็นระบบ
- เพื่อฝึกใช้ฟังก์ชัน รายการ (List) พจนานุกรม (Dictionary) เงื่อนไข และลูป
- เพื่อเรียนรู้การจัดการข้อผิดพลาดด้วย `try-except`
- เพื่อฝึกอ่านและเขียนข้อมูล JSON สำหรับจัดเก็บข้อมูล
- เพื่อฝึกการตรวจสอบและแก้ไขข้อผิดพลาดด้วย Visual Studio Code
- เพื่อเตรียมโครงงานสำหรับจัดเก็บและเผยแพร่บน GitHub

## 3. ความสามารถของระบบ

1. **เพิ่มรายการงาน** สามารถระบุรายละเอียดงานและกำหนดระดับความสำคัญได้
2. **แสดงรายการงานทั้งหมด** แสดงรหัสงาน รายละเอียด สถานะ และระดับความสำคัญ
3. **แสดงงานที่รอดำเนินการ** กรองเฉพาะงานที่ยังไม่เสร็จ
4. **แสดงงานที่เสร็จแล้ว** กรองเฉพาะงานที่ทำเสร็จเรียบร้อย
5. **ค้นหารายการงาน** ค้นหาจากคำสำคัญในรายละเอียดงาน
6. **ทำเครื่องหมายว่างานเสร็จแล้ว** เปลี่ยนสถานะของงานตามรหัสที่ระบุ
7. **ลบรายการงาน** ลบงานที่ไม่ต้องการ พร้อมยืนยันก่อนลบ
8. **บันทึกและออกจากโปรแกรม** บันทึกรายการงานลงไฟล์ JSON ก่อนปิดโปรแกรม

### ระดับความสำคัญของงาน

- `Low` หมายถึง ความสำคัญต่ำ
- `Medium` หมายถึง ความสำคัญปานกลาง ซึ่งเป็นค่าปริยาย
- `High` หมายถึง ความสำคัญสูง

## 4. เครื่องมือและเทคโนโลยี

- **ภาษาโปรแกรม:** Python
- **รูปแบบการจัดเก็บข้อมูล:** JSON
- **โปรแกรมสำหรับพัฒนา:** Visual Studio Code
- **ระบบควบคุมเวอร์ชัน:** Git
- **แพลตฟอร์มจัดเก็บซอร์สโค้ด:** GitHub

## 5. โครงสร้างโปรเจกต์

```text
my-task-manager/
├── src/
│   ├── __init__.py
│   ├── task_data.py
│   └── task_logic.py
├── data/
│   └── tasks.json
├── main.py
├── .gitignore
└── README.md
```

### คำอธิบายไฟล์และโฟลเดอร์

- `src/` เก็บโมดูลที่เกี่ยวข้องกับการทำงานของระบบ
- `src/__init__.py` ใช้กำหนดให้ `src` เป็น Python package
- `src/task_data.py` จัดการอ่านและบันทึกข้อมูลรายการงานในรูปแบบ JSON
- `src/task_logic.py` จัดการการเพิ่ม แสดง ค้นหา กรองสถานะ ทำงานให้เสร็จ และลบงาน
- `data/` ใช้เก็บไฟล์ข้อมูลของโปรแกรม
- `data/tasks.json` ใช้จัดเก็บรายการงาน โดยโปรแกรมสามารถสร้างโฟลเดอร์และไฟล์ที่จำเป็นได้
- `main.py` เป็นไฟล์หลักสำหรับแสดงเมนู รับข้อมูลจากผู้ใช้ และเรียกใช้ฟังก์ชันจากโมดูลอื่น
- `.gitignore` กำหนดไฟล์และโฟลเดอร์ที่ไม่ต้องการให้ Git ติดตาม
- `README.md` อธิบายรายละเอียดและวิธีใช้งานโปรเจกต์

## 6. ข้อกำหนดเบื้องต้น

- ติดตั้ง Python เวอร์ชัน 3.10 ขึ้นไป
- ติดตั้ง Visual Studio Code หรือโปรแกรมแก้ไขโค้ดที่รองรับ Python
- มีไฟล์โปรเจกต์ครบตามโครงสร้างที่กำหนด

โปรแกรมใช้ไลบรารีมาตรฐานของ Python จึงไม่จำเป็นต้องติดตั้งแพ็กเกจเพิ่มเติมสำหรับการทำงานพื้นฐาน

## 7. วิธีติดตั้งและเรียกใช้งาน

### ขั้นตอนที่ 1 เปิดโฟลเดอร์โปรเจกต์

เปิด Visual Studio Code แล้วเลือก `File > Open Folder...` จากนั้นเลือกโฟลเดอร์ `my-task-manager`

### ขั้นตอนที่ 2 เปิด Terminal

เลือก `Terminal > New Terminal` ใน Visual Studio Code

### ขั้นตอนที่ 3 ตรวจสอบเวอร์ชัน Python

```powershell
python --version
```

### ขั้นตอนที่ 4 เริ่มต้นโปรแกรม

```powershell
python main.py
```

เมื่อโปรแกรมเริ่มทำงาน ระบบจะแสดงเมนูหลักและรอรับคำสั่งจากผู้ใช้

## 8. วิธีใช้งานโปรแกรม

เมื่อเริ่มโปรแกรม จะแสดงเมนูดังนี้

```text
======================================
          TASK MANAGER CLI
======================================
  1. Add New Task
  2. List All Tasks
  3. List Pending Tasks
  4. List Completed Tasks
  5. Search Tasks by Keyword
  6. Mark Task as Completed
  7. Delete Task
  8. Save and Exit
======================================
```

### ตัวอย่างการเพิ่มงาน

1. เลือกเมนู `1`
2. กรอกรายละเอียดงาน เช่น `ทำการบ้าน`
3. กำหนดระดับความสำคัญ เช่น `High`
4. ระบบสร้างรหัสงานให้อัตโนมัติและบันทึกข้อมูล

### ตัวอย่างการทำเครื่องหมายว่างานเสร็จแล้ว

1. เลือกเมนู `6`
2. กรอกรหัสงานที่ต้องการ เช่น `1` หรือ `#1`
3. ระบบเปลี่ยนสถานะงานเป็น `Completed`
4. ระบบบันทึกข้อมูลที่เปลี่ยนแปลงลงไฟล์ JSON

### การค้นหาและกรองรายการงาน

- เลือกเมนู `2` เพื่อดูงานทั้งหมด
- เลือกเมนู `3` เพื่อดูงานที่รอดำเนินการ
- เลือกเมนู `4` เพื่อดูงานที่เสร็จแล้ว
- เลือกเมนู `5` แล้วกรอกคำสำคัญเพื่อค้นหารายการงาน

### การลบรายการงาน

1. เลือกเมนู `7`
2. กรอกรหัสงานที่ต้องการลบ
3. ยืนยันด้วย `y` หรือ `yes`
4. หากไม่ต้องการลบ ให้ตอบ `n` หรือกด Enter

### การออกจากโปรแกรม

เลือกเมนู `8` เพื่อบันทึกข้อมูลและออกจากโปรแกรม

## 9. การจัดเก็บข้อมูลและการจัดการข้อผิดพลาด

ระบบใช้ไฟล์ `data/tasks.json` ในการเก็บข้อมูลรายการงาน โดยแต่ละรายการประกอบด้วยรหัสงาน รายละเอียดงาน สถานะ และระดับความสำคัญ

ตัวอย่างข้อมูล:

```json
[
    {
        "id": 1,
        "description": "ทำการบ้าน",
        "completed": false,
        "priority": "High"
    }
]
```

ระบบมีการจัดการข้อผิดพลาดเบื้องต้น เช่น

- แจ้งเตือนเมื่อผู้ใช้กรอกรหัสงานที่ไม่ใช่ตัวเลข
- ปฏิเสธรหัสงานที่ไม่ใช่จำนวนเต็มบวก
- แจ้งเตือนเมื่อกรอกรายละเอียดงานว่าง
- แจ้งเตือนเมื่อตัวเลือกเมนูไม่ถูกต้อง
- ตรวจสอบกรณีไฟล์ JSON มีรูปแบบไม่ถูกต้อง
- จัดการข้อผิดพลาดระหว่างอ่านหรือบันทึกไฟล์
- พยายามบันทึกข้อมูลเมื่อผู้ใช้หยุดโปรแกรมด้วย `Ctrl+C`

## 10. การทดสอบโปรแกรม

ควรทดสอบการทำงานอย่างน้อยดังนี้

1. เพิ่มรายการงานและตรวจสอบว่ามีรหัสงานอัตโนมัติ
2. แสดงรายการงานทั้งหมดและตรวจสอบข้อมูล
3. กรองงานตามสถานะ
4. ค้นหางานด้วยคำสำคัญ
5. เปลี่ยนสถานะงานเป็นเสร็จแล้ว
6. ลบงานและตรวจสอบว่ารายการถูกนำออก
7. ป้อนข้อมูลที่ไม่ถูกต้องเพื่อทดสอบการจัดการข้อผิดพลาด
8. ปิดและเปิดโปรแกรมใหม่เพื่อตรวจสอบว่าข้อมูลยังอยู่
9. ตรวจสอบว่าไฟล์ JSON มีข้อมูลตรงกับรายการงานจริง

## 11. การใช้ Git และ GitHub

หากต้องการจัดเก็บโครงงานไว้บน GitHub ให้เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วใช้คำสั่งต่อไปนี้

```powershell
git init
git add .
git commit -m "Complete Week 7 Task Manager CLI"
```

จากนั้นสร้าง Repository บน GitHub และเชื่อมต่อกับ Repository ที่สร้างไว้

```powershell
git branch -M main
git remote add origin https://github.com/Mydear00/663380145-7_Sec1_Script_Progrming.git
git push -u origin main
```

เปลี่ยน `YOUR_USERNAME` เป็นชื่อผู้ใช้ GitHub ของตนเอง และใช้ URL ของ Repository จริง

หากเคยกำหนด Remote `origin` ไว้แล้ว ให้ตรวจสอบด้วย `git remote -v` ก่อนเพิ่ม Remote ใหม่
