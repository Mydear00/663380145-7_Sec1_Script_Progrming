
# My API Data Fetcher CLI (Week 10)

A Python command-line application demonstrating how to interact with
web APIs and process JSON data.

## Features

- Fetch a single TODO item by ID.
- Fetch and display the first five posts.
- Fetch TODO items by User ID.
- Handle HTTP errors, connection errors, and timeouts.
- Parse JSON responses into Python dictionaries and lists.

## Technologies

- Python 3
- Requests
- JSONPlaceholder REST API

## Installation

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```
