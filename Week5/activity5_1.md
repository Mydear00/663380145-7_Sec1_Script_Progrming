
# Activity 5.1: การประยุกต์ใช้ Dictionary และ Set ในชีวิตจริง

## 1. Dictionary ในเกม

**สถานการณ์:** ระบบเก็บไอเทมของผู้เล่น (Inventory)

ตัวอย่างนี้ใช้ Dictionary เก็บชื่อไอเทมและจำนวนที่ผู้เล่นมี โดยใช้ชื่อไอเทมเป็น Key และจำนวนเป็น Value

### ตัวอย่างโค้ด

```python
inventory = {
    "potion": 5,
    "sword": 1,
    "shield": 1
}

print("Health Potions:", inventory.get("potion", 0))

inventory["potion"] = inventory.get("potion", 0) + 1

print("Updated Inventory:", inventory)
```

### เหตุผล

Dictionary เหมาะกับการเก็บข้อมูลไอเทมในเกม เพราะสามารถใช้ชื่อไอเทมค้นหาจำนวนที่มีได้โดยตรง และปรับจำนวนได้สะดวก เช่น เมื่อผู้เล่นได้รับ Potion เพิ่ม โปรแกรมสามารถเพิ่มจำนวน Potion ใน Inventory ได้ทันที

## 2. Dictionary ในร้านค้าออนไลน์

**สถานการณ์:** ระบบจัดเก็บข้อมูลสินค้า

ตัวอย่างนี้ใช้รหัสสินค้าเป็น Key และเก็บรายละเอียดสินค้า เช่น ชื่อ ราคา และจำนวนสินค้าคงเหลือ ไว้ใน Dictionary

### ตัวอย่างโค้ด

```python
products = {
    "P001": {
        "name": "Keyboard",
        "price": 590,
        "stock": 10
    },
    "P002": {
        "name": "Mouse",
        "price": 250,
        "stock": 20
    }
}

product = products.get("P001")

if product:
    print("Product:", product["name"])
    print("Price:", product["price"])
    print("Stock:", product["stock"])
```

### เหตุผล

Dictionary ช่วยให้ค้นหาสินค้าด้วยรหัสสินค้าได้สะดวก และเข้าถึงรายละเอียดแต่ละรายการได้ เช่น ชื่อ ราคา และจำนวนสินค้าคงเหลือ นอกจากนี้ยังสามารถแก้ไขข้อมูลสินค้าโดยอ้างอิงจากรหัสสินค้าได้อย่างเป็นระบบ

## 3. Set สำหรับจัดการสิทธิ์ผู้ใช้

**สถานการณ์:** ระบบกำหนดสิทธิ์การใช้งาน

ตัวอย่างนี้ใช้ Set เก็บสิทธิ์ของผู้ใช้ โดยไม่เก็บสิทธิ์ที่ซ้ำกัน

### ตัวอย่างโค้ด

```python
user_permissions = {"read", "write", "delete"}

if "write" in user_permissions:
    print("User can write data.")

user_permissions.add("export")
user_permissions.discard("delete")

print("Current permissions:", user_permissions)
```

### เหตุผล

Set เหมาะสำหรับจัดเก็บสิทธิ์ของผู้ใช้ที่ไม่ต้องการให้ซ้ำกัน สามารถตรวจสอบสิทธิ์ด้วย `in` เพิ่มสิทธิ์ด้วย `add()` และลบสิทธิ์ด้วย `discard()` ได้ นอกจากนี้ยังสามารถใช้ Set Operations เพื่อเปรียบเทียบสิทธิ์ระหว่างผู้ใช้หลายกลุ่มได้

## 4. Set สำหรับตรวจสอบข้อมูลจำนวนมาก

**สถานการณ์:** ระบบตรวจสอบ IP Address ที่ถูกบล็อก

ตัวอย่างนี้ใช้ Set เก็บ IP Address ที่ถูกบล็อก และตรวจสอบว่า IP Address ที่ต้องการเข้าถึงระบบอยู่ในรายการหรือไม่

### ตัวอย่างโค้ด

```python
blocked_ips = {
    "192.168.1.10",
    "192.168.1.25",
    "10.0.0.5"
}

ip_address = "192.168.1.25"

if ip_address in blocked_ips:
    print("Access denied.")
else:
    print("Access allowed.")
```

### เหตุผล

Set เหมาะสำหรับเก็บรายการ IP Address ที่ไม่ต้องการให้ซ้ำกัน และตรวจสอบสมาชิกในกลุ่มได้รวดเร็ว โดยทั่วไปการตรวจสอบสมาชิกใน Set มีประสิทธิภาพเฉลี่ย O(1) จึงเหมาะกับข้อมูลจำนวนมากในกรณีที่ไม่จำเป็นต้องรักษาลำดับของข้อมูล

---

## สรุป

Dictionary เหมาะสำหรับจัดเก็บข้อมูลในรูปแบบ Key-Value เช่น ไอเทมในเกมและรายละเอียดสินค้าในร้านค้าออนไลน์ ส่วน Set เหมาะสำหรับจัดเก็บข้อมูลที่ไม่ต้องการให้ซ้ำกัน และใช้ตรวจสอบหรือเปรียบเทียบสมาชิกในกลุ่ม เช่น สิทธิ์ของผู้ใช้และรายการ IP Address ที่ถูกบล็อก

การเลือกใช้โครงสร้างข้อมูลให้เหมาะสมช่วยให้โปรแกรมทำงานได้เป็นระบบ ค้นหาข้อมูลได้สะดวก และมีประสิทธิภาพมากขึ้น
