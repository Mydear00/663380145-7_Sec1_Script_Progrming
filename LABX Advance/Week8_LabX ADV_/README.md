# Week8_LabX ADV_ Agentic Data Processing

## Overview

A configuration-driven data-processing agent using Python standard library.

## Requirements

- Python 3.10 or newer
- No third-party packages required

## Features

1. Load sales data from CSV.
2. Aggregate sales by customer.
3. Save aggregated results to CSV.
4. Convert CSV records to JSON.
5. Load and update nested inventory JSON.
6. Add a new product and query nested fields.
7. Generate an audit report.

## Run

```bash
python main.py
```

## Generated outputs

- `data/processed_sales_by_customer.csv`
- `data/sales_data.json`
- `data/updated_inventory.json`
- `reports/audit_report_YYYYMMDD_HHMMSS.json`
