# Week 7: Introduction to Web Scraping

## วัตถุประสงค์

1. เรียนรู้การดึงข้อมูลจากเว็บไซต์ด้วย Python
2. ใช้ requests ดาวน์โหลด HTML
3. ใช้ BeautifulSoup วิเคราะห์และค้นหาองค์ประกอบ HTML
4. ฝึกจัดการข้อผิดพลาดในการร้องขอข้อมูลจากเว็บไซต์
5. เรียนรู้จริยธรรมในการทำ Web Scraping

## ไลบรารีที่ใช้

- requests
- beautifulsoup4

## คุณสมบัติ

- ดาวน์โหลดเนื้อหา HTML จากเว็บไซต์
- ดึงชื่อหนังสือ
- ค้นหาและแสดงชื่อบท
- จัดการข้อผิดพลาดจากการเชื่อมต่อและ HTTP
- แสดงผลข้อมูลใน Terminal
